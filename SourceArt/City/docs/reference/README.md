# Visual references (from the project owner, 2026-10-20)

Feedback on the first city pass: "the houses look very far from each other and too much space",
"it needs to look like a busy city - this looks like a big village; houses are apart and too much
space around".

- `ref_map_compact_town.png` - top-down map of a compact game town: blocks packed with buildings,
  little leftover grass, streets close together, shops / services everywhere.
- `ref_street_overpass.png` - dense street scene: brick + clapboard buildings tight to the street,
  an elevated highway, power poles, parked cars.
- `ref_dense_town_sunset.webp` - busy small city: 3-7 storey blocks, gas station, police station,
  pines between buildings, utility poles with wires, cars, little empty space.

Targets derived from these: buildings tight to the sidewalk and to each other, block interiors filled
(second-row buildings, garages, parking lots), paved frontages instead of grass strips, utility poles
and wires, parked cars and traffic, trees in the gaps, woodland instead of bare lawns at the edges.
